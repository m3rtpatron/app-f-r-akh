# 💭 Gedanke-Box

Es eifachs App zum Gedanke sortiere: Idee, Reiseziel, Rezept, Gedanke, Iichaufe, Kleider, Wunschlischte – und eigeni Kategorie.

- Alles wird lokal im Browser gspeicheret (kei Konto, kei Server)
- Sueche, Filter nach Kategorie, abhäkle (z.B. bim Iichaufe)
- Backup als JSON exportiere / importiere
- Funktioniert offline und laht sich ufem Handy als App installiere

## Starte
`index.html` im Browser öffne – oder GitHub Pages aktiviere (Settings → Pages → Branch wähle) und d'URL ufem Handy öffne → „Zum Home-Bildschirm“.
